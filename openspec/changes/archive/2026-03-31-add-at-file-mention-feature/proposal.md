## 为什么

@ 文件提及功能对于提高用户生产力至关重要，它允许在聊天对话中快速准确地引用文件。此功能将使用户能够轻松引用项目文件，而无需手动输入完整路径，从而减少错误并节省时间。

## 变更内容

- 添加后端 API 端点以列出空间内的工件（文件和文件夹）
- 在聊天输入区域实现前端 @ 提及功能
- 添加文件搜索和过滤功能，以实现高效的文件查找
- 支持键盘导航和鼠标交互进行文件选择
- 实现文件拖放功能，以实现快速引用

## 功能

### 新增功能
- `file-mention-api`：后端 API，用于列出具有深度控制和缓存的空间工件
- `file-mention-frontend`：前端 @ 提及 UI，具有自动完成和搜索功能
- `file-drag-drop`：文件拖放支持，用于快速插入文件引用

### 修改功能
- `chat-input`：扩展现有聊天输入功能，以支持 @ 文件提及

## 影响

- **后端**：在 spaces.routes.ts 中添加新的 API 路由
- **前端**：修改 ChatView.tsx 和 InputArea.tsx 组件
- **API 客户端**：扩展 client.ts 以包含新的文件列出方法
- **性能**：实现缓存机制以优化文件列表检索
- **用户体验**：通过快速文件引用提高聊天生产力
