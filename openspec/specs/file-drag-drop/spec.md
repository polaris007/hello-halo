# 文件拖放规范

## 概述

文件拖放功能允许用户从文件系统拖动文件并将其拖放到聊天输入区域，自动在对话中创建文件引用。

## 组件

### InputArea 组件

**描述：** 扩展以支持文件拖放功能

**特性：**
- 拖过检测和视觉反馈
- 文件拖放处理
- 文件路径提取和插入
- 无效文件的错误处理

## 用户流程

1. **拖动：** 用户从文件系统选择并拖动文件
2. **悬停：** 当文件在输入区域上方时，系统显示视觉反馈
3. **放置：** 用户在输入区域上方释放文件
4. **处理：** 系统提取文件路径并创建引用
5. **插入：** 文件路径被插入到输入区域

## UI 要求

### 拖过状态

- **视觉反馈：** 更改边框和背景以指示放置区域
- **图标：** 显示文件拖放图标
- **文本：** 显示 "放置以添加文件引用" 消息

### 放置处理

- **加载状态：** 如有需要，显示处理指示器
- **错误处理：** 显示无效文件的错误消息
- **成功反馈：** 平滑插入文件路径

## 技术要求

### 拖放 API

- 使用标准 HTML5 拖放 API
- 支持单个和多个文件拖放
- 适当处理不同文件类型

### 文件路径处理

- 从拖放的文件中提取绝对文件路径
- 在空间上下文中转换为相对路径
- 验证文件在空间内存在
- 格式化文件路径以进行插入

### 浏览器兼容性

- 支持所有主要浏览器（Chrome、Firefox、Safari、Edge）
- 处理拖放实现中的浏览器特定差异
- 为支持有限的浏览器提供回退功能

## 实现说明

- 使用 `onDragOver`、`onDragLeave` 和 `onDrop` 事件
- 阻止默认行为以启用自定义拖放处理
- 使用 `event.dataTransfer` 访问拖放的文件
- 实现文件路径验证和错误处理
- 与现有文件提及功能集成

## 错误处理

- **无效文件：** 显示空间外文件的错误消息
- **权限错误：** 处理无法访问的文件
- **网络问题：** 处理无法处理文件路径的情况
- **浏览器限制：** 为不支持的浏览器提供回退说明

## 无障碍性

- **键盘替代方案：** 确保可以通过键盘添加文件引用
- **屏幕阅读器：** 提供适当的 ARIA 标签和反馈
- **焦点管理：** 在拖放操作期间保持焦点
- **对比度：** 确保视觉反馈满足 WCAG 对比度要求

## 性能考虑

- **拖过性能：** 保持视觉反馈轻量
- **放置处理：** 高效处理文件而不阻塞 UI
- **大型文件：** 处理大型文件拖放而不降低性能
- **多个文件：** 优雅处理多个文件拖放

## 安全考虑

- **路径遍历：** 防止路径遍历攻击
- **文件访问：** 验证文件访问权限
- **恶意文件：** 处理来自拖放文件的潜在安全风险
- **数据清理：** 清理文件路径以防止注入攻击
