# 文件提及前端规范

## 概述

文件提及前端在聊天输入区域实现了 @ 文件提及功能，允许用户通过输入 `@` 并从建议列表中选择来快速引用项目文件。

## 组件

### InputArea 组件

**描述：** 扩展现有的 InputArea 组件以支持 @ 文件提及功能

**特性：**
- @ 符号检测和菜单显示
- 文件搜索和过滤
- 键盘导航支持
- 鼠标交互支持
- 文件选择和插入

### ChatView 组件

**描述：** 修改为加载并将工件列表传递给 InputArea

**特性：**
- 从 API 加载工件
- 缓存工件列表
- 在空间更改时更新工件列表

## 用户流程

1. **触发：** 用户在聊天输入区域中输入 `@`
2. **建议：** 系统显示文件和文件夹列表
3. **过滤：** 随着用户输入，建议会被过滤
4. **选择：** 用户使用键盘或鼠标选择文件
5. **插入：** 选定的文件路径被插入到输入区域

## UI 要求

### 提及菜单

- **位置：** 出现在输入区域上方
- **内容：** 带有图标的文件和文件夹列表
- **导航：** 支持箭头键和鼠标悬停
- **选择：** Enter 或 Tab 选择
- **取消：** Escape 关闭
- **滚动：** 支持长列表

### 文件显示

- **格式：** 显示相对文件路径
- **图标：** 为不同文件类型使用适当的图标
- **高亮：** 高亮匹配文本
- **排序：** 按相关性和文件类型排序

## 交互要求

### 键盘导航

- **向下箭头：** 移动到下一个建议
- **向上箭头：** 移动到上一个建议
- **Enter/Tab：** 选择当前建议
- **Escape：** 关闭菜单

### 鼠标交互

- **悬停：** 高亮建议
- **点击：** 选择建议

### 输入行为

- **@ 检测：** 当输入 `@` 时显示菜单
- **过滤：** 随着用户输入过滤建议
- **插入：** 以反引号格式插入文件路径
- **尾随空格：** 在插入的文件路径后添加空格

## 性能要求

- **菜单显示：** 输入 `@` 后 < 100ms
- **过滤：** 每次按键 < 50ms
- **渲染：** 长列表的平滑滚动
- **缓存：** 缓存工件列表以减少 API 调用

## 实现说明

- 重用现有的 InputArea 组件结构
- 使用 React 状态管理菜单可见性和选择
- 实现文件匹配的模糊搜索
- 优化大型文件列表的渲染
- 对 API 调用使用防抖
- 处理边缘情况（空结果、网络错误）

## 错误处理

- **API 错误：** 显示错误消息并回退到手动输入
- **空结果：** 显示 "未找到文件" 消息
- **网络问题：** 带超时的重试机制
- **权限错误：** 显示适当的错误消息

## 无障碍性

- **键盘导航：** 完整的键盘支持
- **屏幕阅读器：** ARIA 标签和角色
- **焦点管理：** 适当的焦点处理
- **对比度：** 满足 WCAG 对比度要求
